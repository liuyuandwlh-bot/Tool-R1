# 数据说明

版本 1 是完全可复现的合成课程，不是公开真实世界 benchmark。没有人工隐私数据或在线抓取内容。默认 seed=42，训练/验证/测试为 2400/400/800，每类任务等量。

| 任务 | 内容 | 教师动作 |
|---|---|---|
| direct | 两个小整数的箱数相加 | final |
| retrieve | 从审计台账检索特定实体年份的实际出货量 | retrieve → final |
| compute | 五组数量与单价的加权总额 | python → final |
| compose | 检索两年的实际出货量并计算百分比变化 | retrieve → python → final |

模型不必遵循教师顺序；允许零工具、重复检索、直接计算或其他合法策略。工具是否有价值由正确性和成本共同衡量。`source_doc_ids` 只用于离线证据审计，不注入模型输入或奖励的语义判断。

每题独立生成 `NOVA-...` 实体，实体、样本 ID、文档在各划分间不重叠。语料包含预测值、不同年份、相似实体 `-WEST` 等干扰。默认语料为 5400/900/1800 条，BM25 只返回文档 ID、正文和检索分数。

训练及验证使用两种已见措辞模板。测试一半使用已见模板、一半使用第三种未见措辞模板；数学操作和任务类型仍相同。它衡量措辞迁移，不能证明新任务、新领域或真实资料泛化。拆分不重叠也不意味着训练和测试任务分布完全不同。

训练示范由确定性规则构建并由真实执行环境回放。示范文件只存在于训练划分；模型输入只含问题、公共系统提示、历史模型输出和实际工具观察。生成器持有答案用于构建训练目标和最终评分，检索器/Python 都不读取答案表。

数值答案要求单位。整数任务精确校验；百分数按四位小数与明确容差校验。布尔值、非有限数字、含单位的数字字符串、来自模型的评分元数据均被拒绝或判错。JSON 对象、文本和集合校验接口预留，但当前课程只生成数值任务。

`manifest.json` 记录文件 SHA256、数量、模板与数据集指纹；`audit` 检查泄漏边界、证据与哈希。`training.prepare` 进一步验证实际检索包含教师所需文档、Python stdout 支持目标答案。静态审计与工具回放都不等于模型评测。

扩展真实数据时，需要新增具名的数据导入器和来源/许可记录、按来源隔离划分、保留固定文档快照，并以同一数据重新训练所有对照方法。当前项目未下载或验证任何外部 QA 数据。
